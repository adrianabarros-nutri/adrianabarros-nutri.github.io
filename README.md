# Avaliação Física - Adriana Barros

PWA para avaliação física online/offline.

## Publicação no GitHub Pages

Este repositório já está preparado para funcionar no GitHub Pages.

### Opção mais simples
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main** e a pasta **/(root)**.
6. Clique em **Save**.
7. Aguarde o GitHub exibir o endereço do site.

O endereço normalmente ficará no formato:

`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## iPhone/iPad
Abra o link no Safari. Para instalar como app:
**Compartilhar > Adicionar à Tela de Início**.

## Android
Abra no Chrome. O navegador pode oferecer a opção de instalar o aplicativo.

## Windows
Abra no Chrome ou Edge. A aplicação também pode ser instalada como PWA.

## Privacidade
As fotos e os dados do paciente são processados localmente pelo navegador.
O formulário não envia automaticamente as informações para um servidor.
